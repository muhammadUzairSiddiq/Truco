Players will create their own 1v1 matches from within Unity (public or private), with all validation handled in the backend (including balance verification and coin deduction before the match starts).

The admin panel does NOT need to manually create 1v1 matches at this stage.
The admin panel only needs to:
1. View active matches in real time (players, match status, progress).

2. Have manual control to:
* force the closure of a match
* assign a winner ONLY in exceptional cases
Important clarification:
Manual winner assignment is NOT part of the normal game flow.

All normal results should be resolved automatically from the backend (timeouts, abandonment, disconnections, etc.). Manual intervention is only a safety measure for extreme cases, such as:
* both players disconnect simultaneously
* a bug leaves the game locked
* coins are held without a result
Without this, a game with an error could permanently lock players' balances.

Summary:
* Normal result → always automatic (backend as the authority)
* Exceptional failure → the administrator can resolve manually from the panel
Please confirm that you will implement this workflow with the backend as the authority.
