# 🃏 Truco Card

**Truco Card** is a competitive **1v1 multiplayer card game** inspired by the classic Argentinian *Truco*. Players face off in real time, testing skill, bluff, and strategy to claim victory.

---

## 🎮 Gameplay Overview
Truco Card brings the excitement of traditional Truco to the digital arena.  
Players can join quick 1v1 matches or participate in tournaments with multiple competitors. The system handles matchmaking, authentication, and real-time gameplay synchronization through backend APIs.

---

## 🚀 Features

### 🔐 Authentication & User System
- **Login & Register** – Secure user accounts through API.  
- **OTP Email Verification** – Ensures valid player registration.  
- **Player Session Handling** – Maintains session for authenticated users.  
- **User Validation** – Validates player identity and token.  
- **Auth Token System** – Secure API communication using token-based authentication.

### 🧩 Multiplayer System
- **Find Match** – Automatically pairs players in real-time 1v1 battles.  
- **Match Result Handling** – Determines **winner/loser** and updates backend.  
- **Reward System** – Distributes rewards based on match outcomes.

### 🏆 Tournament System
- Supports **4, 8, 16, or more** player brackets.  
- Automated pairing and progression logic.  
- Match tracking and player advancement.

---

## ⚙️ Technology Stack
- **Game Engine:** Unity  
- **Backend API:** Truco Argentina API  
- **Authentication:** Token-based auth with session management  
- **Networking:** Multiplayer matchmaking and room handling with Photon Pun 2

---

## 📡 API Integration
Truco Card uses the **Truco Argentina API** for:
- User authentication  
- Match creation and management  
- Tournament organization  
- Player statistics and session tracking
